SVG via currentColor

SVG has no background — but the engine sets color on every element, and one rule (fill: currentColor) hands that to every shape. The heatmap below is pure engine: each cell is chromatic ink at --fg 0→1. Drag the hue, flip the theme — the whole grid re-resolves.

No .bg anywhere in the SVG — surfaces don't exist there. Every cell, label, and legend square is fill: currentColor resolving the engine's ink. Empty cells use a faint neutral --fg (so they stay grey at any hue, like GitHub); filled cells ramp the chromatic side. The contrast flip still fires, so the ramp re-anchors correctly when you switch to dark.

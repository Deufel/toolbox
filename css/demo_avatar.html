Avatar

A square monogram / icon / image chip, sized in lh so it scales with the type system. Colour it by setting --hue / --bg at the call site.

Scales with --type

The avatar is 2.4lh tall, so it tracks line-height — which tracks --type. Each chip below sets a different --type; the monogram and its chip step in size together, no separate font sizing needed.

AL AL AL AL AL AL AL

And because --scale is regional, a whole cluster rescales at once:

GH KJ ST ↑ --scale: 1.4 region

Disclosure

A bare <details> is the component — native open/close, no JS. The <summary> is the clickable header with a chevron that rotates on open; the body animates its height when motion is on.

Basic

What is this design system?

A small, token-driven CSS system where colour, space, and weight are functions of a few inherited numbers rather than stored palettes. Components are decisionless shapes positioned on scales you control at the call site.

How do I size a component?

Set --type for a local step, or --scale to rescale a whole region. Spacing follows automatically — the type engine drives it.

Can it start expanded?

Yes — add the open attribute. This one is open by default, so the chevron points down and the divider under the summary is showing.

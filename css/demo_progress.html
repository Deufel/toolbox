Progress · Meter · Range

Three native elements sharing one visual language — a pill track with a hue-driven fill. Bare elements, no classes. Fill colour follows --hue.

<progress> — a task filling up

<meter> — a measurement in a range

Manual hue by default (you set --hue, like everything else):

284 / 320 4.8 / 5 2 / 10

Opt-in .smart — the meter's own low/high/optimum bands drive the colour (success / warning / danger), no hand-picked hue:

92% (good) 80% (warn) 71% (low)

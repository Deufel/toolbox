A declarative design system

You declare the intent. The engine resolves it.

Most CSS is imperative: you spell out the exact pixels, weights, and hex values for every state. system.css is declarative — you state where something sits on a few scales, and engines for color, type, and space compute the rest. A component carries a shape; you set its position.

Start with color → Browse the components
Declarative by nature

A component does not have colors or sizes. It has a shape, and it sits at a position on scales the author controls at the call site.

The payoff is the cascade: declare one intent and the dependent decisions follow. Set --type once and font-size, line-height, letter-spacing, and weight all move together. Set --bg and the ink contrast resolves itself. You stop maintaining four properties that must agree.

Imperative · spell out every value color:#1a7f37; font-size:14px;
line-height:20px; font-weight:600;

Four values you must keep in agreement, in every theme, forever.

Declarative · state the position --hue:145; --type:-1;

Two intents. The engine derives the size, leading, weight, and legible ink.

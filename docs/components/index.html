Components

Every entry is a live, zero-author-CSS demo with a theme and scale switcher. The bare semantic elements need no class; the rest are the few things HTML has no element for.

Elements · style the bare semantic tag
Button <button>

Self-shapes by content via :has() — icon, dock, labeled. --lift off its surface.

Table <table>

Booktabs styling — one rule under the head, no row lines. .num for tabular figures.

Blockquote <blockquote>

Tinted surface, chromatic quote ink, generated marks; trailing <cite> attribution.

Disclosure <details>

Native open/close, CSS chevron, card-framed; height animates when motion is on.

Code & Kbd <code> <kbd> <pre>

Monospace family — recessed chip, keycap, code panel.

Progress & Meter <progress> <meter> range

One pill-track+fill language; fill follows --hue. .smart meters self-color.

Forms · a label inside a form is a field
Form fields <form> <label>

Form becomes a recessed panel; controls go raised and borderless. Validation rides real ARIA.

Components · a class for what HTML lacks an element for
Card .card / .Card

A painted surface — set --bg to place it in the depth stack. Quiet or vibrant edge.

Alert .alert

A standing message with a semantic hue. Add a helper and your own ARIA role.

Tag .tag

Small dense label. State via data-ui-state or aria-disabled.

Avatar .avatar

Square monogram, image, or icon chip, sized in lh. Color inline.

Breadcrumbs .crumbs

Links ending in aria-current="page". Separators are generated, never in markup.

Tabs .tabs

Segmented radio control on a role="group". --type rescales the whole control.

Patterns · whole-page compositions
Syntax highlighting Custom Highlight API

Tokens named <lang>-<kind> via the CSS Custom Highlight API — no wrapper spans.

App shell .page · 10 slots

The full .page grid — header, rails, main, aside, footer. Only regions scroll.

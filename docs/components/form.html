Form fields

A <label> inside a form is a field — no class. Feedback <small> sits between label and input, always present at a fixed line, so toggling error text causes zero layout shift. Validation rides aria-invalid.

datalist · input autocomplete (popup is OS-rendered, not stylable)

A <datalist> gives an <input> autocomplete suggestions. Unlike the customizable select, the suggestion popup is drawn by the OS and can't be styled — only the input is ours. Type to see it.

customizable select · 2026 base-select · styled picker

Plain <select> + <option> — no extra markup. The browser shows the selected value; we style the picker and options from the engine. Options lift on hover, the selected one reads bold. Native fallback where unsupported.

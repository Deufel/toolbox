Demo of .navbar-dynamic at commit 42a5e64. Above 1024px, the nav looks identical to .navbar — full 14em column, horizontal rows, icon + label + right-aligned tag. Below 1024px, each row collapses to a square: icon centered above a truncated label, with the tag pinned to the top-right corner.

The "Analytics dashboard" entry is deliberately long so you can see the truncate behavior kick in at the collapsed shape — the label ellipsizes rather than wrapping or breaking the square aspect ratio.

Try resizing across the 1024px boundary; the swap should be instant. Toggle .centered at any viewport to confirm both shapes still work inside a centered page.
